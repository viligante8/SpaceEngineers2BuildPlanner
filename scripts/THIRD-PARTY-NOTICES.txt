Third-party components bundled with Build Planner
=================================================

Build Planner ships the following libraries alongside BuildPlanner.dll. Both are
required at runtime: the plugin patches game methods through MonoMod, which uses
Mono.Cecil to read assemblies.

Both are distributed under the MIT License.
